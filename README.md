# Presentación Automática

Visor web de presentaciones con reproducción automática y controles interactivos.

## Características

- Reproducción automática con intervalos configurables (2, 3, 5, 7, 10 segundos)
- Modo pantalla completa
- Navegación manual (flechas, clicks)
- Modo bucle infinito
- Responsive y compatible con dispositivos móviles

## Despliegue

### Vercel
El proyecto está configurado para desplegarse automáticamente en Vercel.

### Local
Simplemente abre `presentacion-completa.html` en tu navegador.

## Controles

- **Espacio/Enter**: Reproducir/Pausar
- **Flechas izquierda/derecha**: Navegación manual
- **F**: Pantalla completa
- **ESC**: Salir de pantalla completa

## Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla
- Imágenes embebidas en base64
